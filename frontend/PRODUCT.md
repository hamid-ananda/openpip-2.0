# Product

## Register

product

## Users

Molecular biologists and bioinformaticians at research institutes and universities. Primary task: search a gene or UniProt ID, orient themselves in the resulting interaction network, apply filters, and export data for downstream analysis. Occasional users include wet-lab biologists who need the network view to generate hypotheses but are not bioinformatics experts.

## Product Purpose

openPIP is a searchable protein-protein interaction database and network visualizer. It surfaces curated interaction data (HI-Union, Literature) as an interactive Cytoscape network alongside enrichment tables and downloadable datasets. Success means a researcher can search, filter, orient, and export within one focused session.

## Brand Personality

Precise. Clean. Scientific.

## Anti-references

- Default grey Cytoscape output: flat grey nodes on white, no hierarchy, looks unfinished.
- Neon/cyberpunk network viz: glowing edges on dark background, screensaver aesthetic.
- Generic "biotech blue": teal-and-white stock science look with cell imagery.
- SaaS dashboard chrome: heavy navigation, marketing copy inside a tool.

## Design Principles

1. **Data is the design.** The network and its annotations are the product. Chrome exists to frame them, not to compete.
2. **Hierarchy signals meaning.** Visual weight should reflect biological importance: query proteins are the anchors, interactors orbit them. Edges with higher confidence should read as more substantial.
3. **Precision over decoration.** Every visual choice should help the researcher orient, filter, or extract insight. If a detail doesn't serve that, remove it.
4. **Scientific figure quality.** The network should look like it belongs in a journal figure: clean, legible, print-worthy. Not a web widget.

## Accessibility & Inclusion

WCAG AA minimum. Edge colors must remain distinguishable for the most common forms of color vision deficiency (deuteranopia/protanopia) when possible. A sidebar toggle to adjust node/edge appearance is planned.
